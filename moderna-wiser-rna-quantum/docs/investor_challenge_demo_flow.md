# RNAQ Labs Demo Flow for Different Audiences

## Challenge reviewer
Focus on reproducibility, project architecture, QUBO formulation, validation, and safe claims.

## Professor or technical mentor
Focus on traceability: sequence -> candidate elements -> variables -> coefficients -> graph conflicts -> validation -> report.

## Investor or startup mentor
Focus on the product wedge: one biological input generates a guided analysis, risk label, solver path, and report that could reduce trial-and-error in research workflows.

## Missing audiences to prepare for
- Student learners: explain the pipeline as an educational tool.
- Research labs: emphasize reproducible benchmark reports.
- Biotech collaborators: emphasize decision support and limitations.
- Quantum software groups: emphasize QUBO-to-Ising, QAOA/VQE readiness, and graph-aware compression.
