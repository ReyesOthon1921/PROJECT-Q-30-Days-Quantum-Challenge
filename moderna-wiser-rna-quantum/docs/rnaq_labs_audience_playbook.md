# RNAQ Labs Audience Demo Playbook

## Challenge / Judge
Show reproducibility, validation discipline, QUBO variables, graph risk, solver path, and safe claims.

## Investor / Mentor
Show product value: one scientific input becomes an explainable decision report.

## Professor / Research Reviewer
Show assumptions, validation limits, exact-validation priority, and where graph diagnostics connect to the benchmark pipeline.

## YC / Startup Conversation
Frame the MVP as AI-native scientific optimization infrastructure. Keep the wedge narrow and ask for feedback on first customer segment.

## Student / Learner
Use the app to teach how RNA input becomes candidate pairs, candidate stems, QUBO variables, and a graph-risk explanation.
