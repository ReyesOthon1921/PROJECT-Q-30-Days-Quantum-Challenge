\# Deployment Prep — Classical-to-Quantum RNA Folding Dashboard



\## Purpose



This project is prepared for future web deployment.



The dashboard currently runs locally with Flask and includes:



\- RNA sequence preprocessing

\- dot-bracket validation

\- ViennaRNA benchmark

\- candidate pair and stem generation

\- stem-based QUBO construction

\- greedy solver

\- simulated annealing solver

\- QAOA readiness prototype

\- VQE readiness prototype

\- solver comparison

\- scaling analysis

\- professional UI theme

\- RNA visualization canvas
