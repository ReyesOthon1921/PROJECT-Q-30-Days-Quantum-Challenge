# Screen Specification

## 1. Operations dashboard

Show:

- open manual tasks;
- pending decisions;
- recent observations;
- failed or unverified assets;
- offline queue;
- active experiments;
- next required samples;
- data export and backup status.

## 2. Field entry

Large mobile controls for:

- plot;
- measurement;
- value and unit;
- instrument;
- quality;
- time;
- notes;
- optional photo.

Must support offline queueing.

## 3. Manual work

- create task;
- assign person;
- priority;
- instructions;
- complete task;
- completion notes;
- parts used;
- follow-up required.

## 4. Acre registry

Tabs for:

- plots;
- assets;
- experiments;
- samples;
- people;
- revisions.

## 5. Decision gate

Show:

- proposed action;
- source type and version;
- evidence;
- uncertainty;
- constraints;
- approve, reject, or edit;
- required outcome measurement.

## 6. Research comparison

Later page comparing:

- rule;
- statistical baseline;
- ML;
- graph model;
- optimizer;
- quantum-inspired method;
- simulator;
- QPU result.
