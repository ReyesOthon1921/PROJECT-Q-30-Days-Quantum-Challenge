# AgroQ Phase 3.1 / 3.2 Coding Package

## Added

- Founder administrator account configuration
- Administrator-only control center
- DNA/RNA lookup through NCBI Nuccore
- Protein lookup through NCBI Protein
- One-click record insertion and experiment linking
- FASTA, JSON, and CSV export
- Sequence provenance, checksum, and audit records
- Three demonstration experiments
- Administrator approval gate
- React Admin & Sequence Lab
- Architecture diagrams
- Automated tests

## Demonstration experiments

1. Slobolt lettuce low-water biomass-retention phenotype
2. Slobolt lettuce heat-resilience and bolting-delay phenotype
3. Lettuce candidate sequence-to-pigmentation evidence map

The first two are synthetic scenario demonstrations. The third uses public sequence references. None claims creation of a new plant variety or proof of genetic causality.
