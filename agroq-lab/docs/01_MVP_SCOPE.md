# MVP Scope

## Must-have capabilities

| Capability | MVP behavior |
|---|---|
| Plot registry | Create and view traceable experimental blocks |
| Asset registry | Track gateways, tools, probes, nodes, revisions, and status |
| Manual observations | Enter environmental, plant, organism, and equipment observations |
| Offline queue | Retain unsent entries on the field device |
| Manual work | Create, assign, complete, and document tasks |
| Experiment registry | Store hypothesis, plot, owner, and status |
| Recommendations | Record rule, model, or optimization proposals |
| Human approval | Approve, reject, or edit with notes and reviewer |
| Data export | Export JSON and CSV for backup and analysis |
| Health status | Show whether the local gateway is reachable |

## Should-have after the first demonstration

- Plot map with local coordinates.
- Photo attachment and image metadata.
- Authentication and roles.
- Audit-event table.
- Calibration records.
- Sample chain of custody.
- Sensor ingestion endpoint.
- Simple threshold and forecasting baselines.
- Model registry and evaluation page.
