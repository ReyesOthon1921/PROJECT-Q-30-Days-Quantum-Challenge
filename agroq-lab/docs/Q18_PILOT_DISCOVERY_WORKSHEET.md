# AgroQ Q18 Pilot Discovery Worksheet

## Contact and site

- Contact
- Organization
- Site type
- Region
- Named owner
- Named reviewer

## Current manual workflow

Document the existing workflow before proposing automation.

## Available infrastructure

- Internet and local network
- Computers and mobile devices
- Existing sensors
- Existing databases or spreadsheets
- Backup process
- Staff availability

## Data sources

List only data that the participant is authorized to provide.

## Constraints

- Privacy
- Security
- Scheduling
- Offline operation
- Maintenance
- Training
- Regulatory or organizational rules

## Proposed controlled-beta scope

Use the smallest workflow that can produce meaningful evidence.

## Exclusion scope

Explicitly exclude:

- automatic equipment control;
- unsafe field procedures;
- chemical recommendations without authorized review;
- production performance claims;
- quantum-advantage claims;
- physical sensor integration before the separate field-acceptance gate.

## Approval rule

A pilot requires a documented manual workflow, proposed scope, exclusion scope, named owner, named reviewer, limitations, and rollback plan.
